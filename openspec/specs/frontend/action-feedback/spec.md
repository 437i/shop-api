# frontend/action-feedback Specification

## Purpose

Определяет обратную связь по действиям пользователя в административной панели: визуальное подтверждение успешной мутации, возможность повторить неудачную загрузку списка и правила исключения при завершении сессии.

## Requirements

### Requirement: Успешная мутация подтверждается уведомлением

Система MUST отображать одно визуальное уведомление об успехе после успешного ответа сервера на мутацию, изменяющую данные.

#### Scenario: Успешный ответ сервера на мутацию
- **WHEN** мутация завершилась успешным ответом сервера
- **THEN** система отображает уведомление об успешном выполнении действия

#### Scenario: Неуспешный ответ сервера на мутацию
- **WHEN** мутация завершилась ошибкой 400, 404, 409, 500, 503 или сетевой ошибкой
- **THEN** система не отображает уведомление об успехе
- **THEN** сообщение об ошибке остаётся в том месте, где оно отображалось до этого

#### Scenario: Последовательные успешные мутации
- **WHEN** пользователь последовательно выполняет несколько успешных мутаций
- **THEN** каждая из них сопровождается отдельным уведомлением

### Requirement: Ошибка загрузки списка предлагает повторную загрузку

Система MUST отображать действие повторной загрузки вместе с сообщением об ошибке, возникшей при загрузке основного списка административного раздела.

#### Scenario: Ошибка загрузки списка
- **WHEN** запрос за основным списком раздела завершился ошибкой
- **THEN** система отображает сообщение об ошибке
- **THEN** система отображает действие «Повторить»

#### Scenario: Активация действия «Повторить»
- **WHEN** пользователь активирует действие «Повторить»
- **THEN** система повторно отправляет запрос за тем же списком

#### Scenario: Повторный запрос находится в процессе выполнения
- **WHEN** повторный запрос за списком находится в процессе выполнения
- **THEN** действие «Повторить» недоступно
- **THEN** система отображает, что повторный запрос выполняется

#### Scenario: Повторный запрос успешен
- **WHEN** повторный запрос за списком завершился успешным ответом
- **THEN** система отображает список
- **THEN** действие «Повторить» не отображается

#### Scenario: Повторный запрос неуспешен
- **WHEN** повторный запрос за списком завершился ошибкой
- **THEN** система отображает сообщение об ошибке
- **THEN** действие «Повторить» доступно для следующей попытки

### Requirement: Завершение сессии не порождает обратную связь

Система MUST NOT отображать уведомление или действие повторной загрузки в ответ на код 401.

#### Scenario: Ответ 401 на запрос списка
- **WHEN** запрос за списком вернул 401
- **THEN** действие «Повторить» не отображается
- **THEN** система не отображает уведомление об ошибке

#### Scenario: Ответ 401 на мутацию
- **WHEN** мутация вернула 401
- **THEN** система не отображает уведомление об успехе

### Requirement: Тексты обратной связи локализованы

Система MUST отображать тексты уведомлений и действия повторной загрузки на выбранном языке интерфейса.

#### Scenario: Английский язык
- **WHEN** выбранный язык интерфейса — английский
- **THEN** тексты уведомлений и действия «Повторить» отображаются на английском языке

#### Scenario: Русский язык
- **WHEN** выбранный язык интерфейса — русский
- **THEN** тексты уведомлений и действия «Повторить» отображаются на русском языке
