# Spec Delta

## MODIFIED Requirements

### Requirement: Административный layout содержит навигацию

Система MUST отображать навигационное меню с доступными разделами административного интерфейса.

#### Scenario: Отображение навигационного меню
- **WHEN** пользователь находится на защищённой странице
- **THEN** система отображает sidebar с пунктами меню: "Clients", "Products", "Suppliers"
- **THEN** активный раздел визуально выделен
- **THEN** текущий активный раздел соответствует открытому маршруту раздела

#### Scenario: Переход в раздел поставщиков
- **WHEN** пользователь активирует пункт меню "Suppliers"
- **THEN** система открывает страницу `/suppliers`
- **THEN** пункт "Suppliers" визуально выделен как активный

#### Scenario: Неактивные разделы недоступны
- **WHEN** пользователь находится в административном layout
- **THEN** пункт меню "Products" отображается как disabled
- **THEN** нажатие на disabled пункт не выполняет навигацию
