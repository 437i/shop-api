# Spec Delta

## Purpose

Управление фотографией товара в административной панели: загрузка, просмотр, замена и удаление фотографии через существующие операции API изображений, с отображением результата, обработкой ошибок и локализацией EN/RU.

## ADDED Requirements

### Requirement: Диалог управления фотографией товара

Система MUST открывать диалог управления фотографией по действию из строки списка товаров и MUST показывать в нём имя товара, его текущую фотографию либо состояние отсутствия фотографии.

#### Scenario: Открытие диалога

- **WHEN** пользователь активирует управление фотографией в строке товара
- **THEN** система открывает диалог, содержащий имя этого товара
- **THEN** диалог запрашивает фотографию товара по `GET /api/v1/products/{id}/image` с Bearer-авторизацией

#### Scenario: Фотография загружается

- **WHEN** запрос фотографии товара выполняется
- **THEN** система отображает состояние ожидания
- **THEN** состояние отсутствия фотографии не отображается до завершения запроса

#### Scenario: Фотография товара показана

- **WHEN** GET-запрос на `/api/v1/products/{id}/image` вернул 200 с телом изображения
- **THEN** система отображает изображение, полученное из ответа
- **THEN** изображение получает доступное имя, описывающее товар
- **THEN** система освобождает временную ссылку на изображение при закрытии диалога

#### Scenario: У товара нет фотографии

- **WHEN** GET-запрос на `/api/v1/products/{id}/image` вернул 404
- **THEN** система отображает состояние отсутствия фотографии вместо изображения
- **THEN** система не отображает сообщение об ошибке

#### Scenario: Товар без фотографии: доступно только действие загрузки

- **WHEN** у товара нет фотографии
- **THEN** система отображает действие загрузки фотографии
- **THEN** система не отображает действия замены и удаления фотографии

#### Scenario: Товар с фотографией: доступны замена и удаление

- **WHEN** у товара есть фотография
- **THEN** система отображает действия замены и удаления фотографии
- **THEN** система не отображает действие загрузки фотографии

#### Scenario: Ошибка загрузки фотографии

- **WHEN** GET-запрос на `/api/v1/products/{id}/image` завершился ответом 400, 500, 503 или сетевой ошибкой
- **THEN** система отображает сообщение из поля `message` ответа, а при его отсутствии — локализованное сообщение об ошибке
- **THEN** состояние отсутствия фотографии не отображается

#### Scenario: Завершение сессии при загрузке фотографии

- **WHEN** GET-запрос на `/api/v1/products/{id}/image` завершился ответом 401
- **THEN** система удаляет токен, очищает кеш и перенаправляет на `/auth/login` в соответствии с существующим глобальным поведением

### Requirement: Загрузка фотографии товара

Система MUST отправлять выбранный файл на `POST /api/v1/products/{id}/image` с Bearer-авторизацией как тело запроса без преобразования в JSON и MUST подтверждать результат уведомлением.

#### Scenario: Успешная загрузка

- **WHEN** пользователь выбрал файл и отправил форму загрузки
- **THEN** система отправляет POST-запрос на `/api/v1/products/{id}/image` с телом, равным содержимому файла
- **THEN** при ответе 201 система отображает уведомление об успешной загрузке фотографии
- **THEN** система инвалидирует кеш списка товаров и кеш фотографии товара
- **THEN** диалог отображает загруженную фотографию

#### Scenario: Товар без фотографии после загрузки

- **WHEN** POST-запрос на `/api/v1/products/{id}/image` вернул 201
- **THEN** обновлённый ответ `GET /api/v1/products` содержит заполненное поле `image_id` этого товара

#### Scenario: Ошибка загрузки

- **WHEN** POST-запрос завершился ответом 400, 404 или 500 с полем `message` (например, `empty image`, `invalid product id`, `product not found`)
- **THEN** система отображает сообщение из поля `message`
- **THEN** если поле `message` отсутствует, система отображает локализованное сообщение об ошибке
- **THEN** форма загрузки остаётся открытой, выбранный файл сохраняется

#### Scenario: Сетевая ошибка загрузки

- **WHEN** POST-запрос не вернул ответ (timeout, network error)
- **THEN** система отображает локализованное сообщение о сетевой ошибке
- **THEN** форма загрузки остаётся открытой

#### Scenario: Блокировка повторной загрузки

- **WHEN** запрос загрузки выполняется
- **THEN** элементы управления загрузкой становятся disabled и отображают текст выполнения
- **THEN** повторная отправка невозможна до завершения запроса

### Requirement: Замена фотографии товара

Система MUST заменять существующую фотографию товара запросом `PUT /api/v1/images/{id}` с телом, равным содержимому нового файла, где `id` берётся из `image_id` товара в актуальном состоянии.

#### Scenario: Успешная замена

- **WHEN** у товара заполнено поле `image_id` и пользователь отправил новый файл
- **THEN** система отправляет PUT-запрос на `/api/v1/images/{id}` с телом, равным содержимому файла
- **THEN** при ответе 204 система отображает уведомление об успешной замене фотографии
- **THEN** система инвалидирует кеш списка товаров и кеш фотографии товара
- **THEN** диалог отображает новую фотографию

#### Scenario: Ошибка замены

- **WHEN** PUT-запрос завершился ответом 400, 404 или 500 с полем `message` (например, `empty image`, `invalid image id`, `image not found`)
- **THEN** система отображает сообщение из поля `message`
- **THEN** если поле `message` отсутствует, система отображает локализованное сообщение об ошибке
- **THEN** диалог продолжает показывать прежнюю фотографию

### Requirement: Удаление фотографии товара

Система MUST удалять фотографию товара запросом `DELETE /api/v1/images/{id}` после явного подтверждения, где `id` берётся из `image_id` товара в актуальном состоянии.

#### Scenario: Подтверждение удаления

- **WHEN** пользователь активирует удаление фотографии
- **THEN** система отображает диалог подтверждения с именем товара
- **THEN** доступное имя действия содержит имя товара

#### Scenario: Отмена удаления

- **WHEN** пользователь отменяет подтверждение
- **THEN** запрос на удаление не отправляется
- **THEN** фотография товара остаётся отображаемой

#### Scenario: Успешное удаление

- **WHEN** пользователь подтверждает удаление
- **THEN** система отправляет DELETE-запрос на `/api/v1/images/{id}`
- **THEN** при ответе 204 система отображает уведомление об успешном удалении фотографии
- **THEN** система инвалидирует кеш списка товаров и кеш фотографии товара
- **THEN** диалог отображает состояние отсутствия фотографии

#### Scenario: Ошибка удаления

- **WHEN** DELETE-запрос завершился ответом 400, 404 или 500 с полем `message`
- **THEN** система отображает сообщение из поля `message`
- **THEN** если поле `message` отсутствует, система отображает локализованное сообщение об ошибке
- **THEN** фотография товара остаётся отображаемой

### Requirement: Клиентская валидация файла изображения

Система MUST проверять выбранный файл до отправки: файл выбран, файл не пустой и его размер не превышает 10 МиБ.

#### Scenario: Файл не выбран

- **WHEN** пользователь отправляет форму без выбранного файла
- **THEN** система отображает сообщение валидации
- **THEN** запрос на `/api/v1/products/{id}/image` не отправляется

#### Scenario: Пустой файл

- **WHEN** выбранный файл не содержит данных
- **THEN** система отображает сообщение валидации
- **THEN** запрос на `/api/v1/products/{id}/image` не отправляется

#### Scenario: Файл больше допустимого размера

- **WHEN** размер выбранного файла превышает 10 МиБ
- **THEN** система отображает сообщение валидации о превышении размера
- **THEN** запрос на `/api/v1/products/{id}/image` не отправляется

#### Scenario: Допустимый файл

- **WHEN** выбран непустой файл размером не более 10 МиБ
- **THEN** система считает файл допустимым и не блокирует отправку

### Requirement: Ошибки операций с фотографией отображаются

Система MUST отображать сообщение сервера при неуспешном ответе операции с фотографией и MUST сохранять выбранный файл в открытой форме.

#### Scenario: Ошибка 400 с сообщением

- **WHEN** операция с фотографией завершается ответом 400 с полем `message` (например, `empty image`, `invalid image id`, `invalid product id`)
- **THEN** система отображает сообщение из поля `message`

#### Scenario: Ошибка 400 без сообщения

- **WHEN** операция с фотографией завершается ответом 400 без поля `message`
- **THEN** система отображает локализованное сообщение о некорректном запросе

#### Scenario: Ошибка 404

- **WHEN** операция с фотографией завершается ответом 404 с полем `message` (например, `image not found`, `product not found`)
- **THEN** система отображает сообщение из поля `message`
- **THEN** если поле `message` отсутствует, система отображает локализованное сообщение о том, что изображение не найдено

#### Scenario: Ошибки сервера и сеть

- **WHEN** операция завершается ответом 500 или 503 без поля `message`
- **THEN** система отображает локализованное сообщение об ошибке сервера
- **WHEN** запрос не возвращает ответ (timeout, network error)
- **THEN** система отображает локализованное сообщение о сетевой ошибке

#### Scenario: Ввод сохраняется при ошибке

- **WHEN** отправка формы с фотографией завершается ошибкой
- **THEN** форма остаётся открытой
- **THEN** выбранный файл сохраняется

#### Scenario: Успешная операция скрывает ошибку другой операции

- **WHEN** одна операция с фотографией завершилась ошибкой, а другая операция завершилась успешно
- **THEN** система не отображает сообщение об ошибке завершившейся с ошибкой операции

#### Scenario: 401 завершает сессию

- **WHEN** операция с фотографией завершается ответом 401
- **THEN** система удаляет токен, очищает кеш и перенаправляет на `/auth/login` в соответствии с существующим глобальным поведением
- **THEN** система не отображает сообщение об ошибке

### Requirement: Локализация операций с фотографией

Система MUST отображать все тексты операций с фотографией (действие в строке списка, подписи диалога, состояния загрузки и отсутствия фотографии, доступное имя фотографии, подтверждение удаления, сообщения валидации и ошибок) на выбранном языке: английском или русском.

#### Scenario: Английский язык

- **WHEN** выбранный язык — английский
- **THEN** действие управления фотографией, тексты диалога, состояния, доступное имя фотографии, подтверждение удаления и сообщения валидации отображаются на английском

#### Scenario: Русский язык

- **WHEN** выбранный язык — русский
- **THEN** действие управления фотографией, тексты диалога, состояния, доступное имя фотографии, подтверждение удаления и сообщения валидации отображаются на русском
