# Spec Delta

## ADDED Requirements

### Requirement: Управление фотографией доступно из строки списка

Система MUST предоставлять в меню действий каждой строки списка товаров действие управления фотографией, открывающее диалог работы с фотографией этого товара.

#### Scenario: Действие в меню строки

- **WHEN** пользователь открывает меню действий строки товара
- **THEN** система отображает действие управления фотографией
- **THEN** активация действия открывает диалог фотографии этого товара

#### Scenario: Действие доступно в каждой строке

- **WHEN** список товаров содержит несколько товаров
- **THEN** действие управления фотографией доступно в меню действий каждой строки
