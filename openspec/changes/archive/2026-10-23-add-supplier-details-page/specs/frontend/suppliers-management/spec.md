# Spec Delta

## ADDED Requirements

### Requirement: Переход к карточке поставщика из строки списка

Система MUST предоставлять в меню действий каждой строки списка поставщиков действие перехода к карточке поставщика, открывающее страницу `/suppliers/{id}`, где `{id}` — идентификатор поставщика этой строки.

#### Scenario: Действие в меню строки

- **WHEN** пользователь открывает меню действий строки поставщика
- **THEN** система отображает действие перехода к карточке поставщика
- **THEN** активация действия открывает страницу `/suppliers/{id}` этого поставщика

#### Scenario: Действие доступно в каждой строке

- **WHEN** список поставщиков содержит несколько поставщиков
- **THEN** действие перехода к карточке доступно в меню действий каждой строки
- **THEN** колонки таблицы, меню изменения адреса и удаления не изменяются
