# Spec Delta

## ADDED Requirements

### Requirement: Ошибка загрузки списка клиентов предлагает повторную загрузку

Система MUST отображать в состоянии ошибки загрузки списка клиентов действие «Повторить», повторяющее запрос `GET /api/v1/clients`.

#### Scenario: Запрос списка клиентов завершился ошибкой
- **WHEN** GET-запрос на `/api/v1/clients` завершился ошибкой 400, 500, 503 или сетевой ошибкой
- **THEN** система отображает Alert с сообщением об ошибке
- **THEN** система отображает в этом Alert действие «Повторить»

#### Scenario: Повторная загрузка списка клиентов
- **WHEN** пользователь активирует действие «Повторить»
- **THEN** система повторно отправляет GET-запрос на `/api/v1/clients`

#### Scenario: Повторная загрузка успешна
- **WHEN** повторный GET-запрос на `/api/v1/clients` вернул 200 с массивом клиентов
- **THEN** система отображает таблицу клиентов
- **THEN** действие «Повторить» не отображается
