# Spec Delta

## Purpose

Отображает список клиентов административного интерфейса с интеграцией GET /api/v1/clients и обработкой всех возможных состояний загрузки и ошибок.

## ADDED Requirements

### Requirement: Страница отправляет запрос на список клиентов

Система MUST отправлять GET-запрос на `/api/v1/clients` с Bearer-авторизацией при загрузке страницы.

#### Scenario: Запрос с Bearer токеном
- **WHEN** пользователь открывает страницу `/clients`
- **THEN** система отправляет GET-запрос на `/api/v1/clients` с заголовком `Authorization: Bearer <token>`, где `<token>` — значение из localStorage под ключом `auth_token`

### Requirement: Состояние загрузки отображает skeleton loader

Система MUST отображать skeleton loader во время загрузки данных.

#### Scenario: Загрузка данных
- **WHEN** пользователь открывает страницу `/clients` и запрос к API находится в процессе выполнения
- **THEN** система отображает skeleton loader вместо таблицы
- **THEN** skeleton содержит 5 строк с заглушками колонок

### Requirement: Успешный ответ с данными отображает таблицу

Система MUST отображать таблицу со списком клиентов при успешном ответе 200 с непустым массивом.

#### Scenario: Успешный ответ с клиентами
- **WHEN** GET-запрос на `/api/v1/clients` возвращает 200 с массивом клиентов
- **THEN** система отображает таблицу с колонками: Name, Surname, Birthday, Gender, Registration Date
- **THEN** каждая строка таблицы соответствует одному клиенту из массива `internal_client.Response[]`
- **THEN** колонка "Name" содержит значение поля `name`
- **THEN** колонка "Surname" содержит значение поля `surname`
- **THEN** колонка "Birthday" содержит отформатированное значение поля `birthday` (формат YYYY-MM-DD)
- **THEN** колонка "Gender" содержит значение поля `gender`
- **THEN** колонка "Registration Date" содержит отформатированное значение поля `registration_date` (формат YYYY-MM-DD HH:mm)

### Requirement: Успешный ответ с пустым массивом отображает empty state

Система MUST отображать empty state при успешном ответе 200 с пустым массивом клиентов.

#### Scenario: Пустой список клиентов
- **WHEN** GET-запрос на `/api/v1/clients` возвращает 200 с пустым массивом `[]`
- **THEN** система отображает сообщение "No clients found"
- **THEN** система отображает иллюстрацию или иконку пустого состояния
- **THEN** таблица не отображается

### Requirement: Ошибка 401 перенаправляет на вход

Система MUST обработать ответ 401 как истекший или невалидный токен и завершить сессию.

#### Scenario: Unauthorized response
- **WHEN** GET-запрос на `/api/v1/clients` возвращает 401
- **THEN** система удаляет токен из localStorage
- **THEN** система очищает кеш TanStack Query
- **THEN** система перенаправляет пользователя на `/auth/login`

### Requirement: Ошибки 400 и 500 отображаются на странице

Система MUST отображать сообщение об ошибке при неуспешных ответах 400 или 500.

#### Scenario: Bad Request (400)
- **WHEN** GET-запрос на `/api/v1/clients` возвращает 400
- **THEN** система отображает Alert с сообщением из поля `message` ErrorResponse
- **THEN** если поле `message` отсутствует, система отображает "Invalid request"
- **THEN** таблица не отображается

#### Scenario: Internal Server Error (500)
- **WHEN** GET-запрос на `/api/v1/clients` возвращает 500
- **THEN** система отображает Alert с сообщением из поля `message` ErrorResponse
- **THEN** если поле `message` отсутствует, система отображает "Server error. Please try again later."
- **THEN** таблица не отображается

#### Scenario: Сетевая ошибка без ответа
- **WHEN** GET-запрос на `/api/v1/clients` не возвращает ответ (timeout, network error)
- **THEN** система отображает Alert с сообщением "Network error. Please try again."
- **THEN** таблица не отображается

### Requirement: Поддержка локализации таблицы

Система MUST отображать заголовки таблицы и сообщения на выбранном языке.

#### Scenario: Английский язык
- **WHEN** пользователь открывает страницу `/clients` и выбранный язык — английский
- **THEN** заголовки колонок отображаются на английском: "Name", "Surname", "Birthday", "Gender", "Registration Date"
- **THEN** сообщения об ошибках и empty state отображаются на английском

#### Scenario: Русский язык
- **WHEN** пользователь открывает страницу `/clients` и выбранный язык — русский
- **THEN** заголовки колонок отображаются на русском: "Имя", "Фамилия", "Дата рождения", "Пол", "Дата регистрации"
- **THEN** сообщения об ошибках и empty state отображаются на русском

### Requirement: Автоматическое обновление при повторном фокусе

Система MUST использовать TanStack Query для кеширования данных и автоматического обновления при возврате на страницу.

#### Scenario: Возврат на страницу из другой вкладки
- **WHEN** пользователь открывает страницу `/clients`, затем переключается на другую вкладку, затем возвращается
- **THEN** TanStack Query автоматически повторяет запрос на `/api/v1/clients` для получения актуальных данных
- **THEN** во время обновления данные из кеша остаются отображёнными

#### Scenario: Повторное открытие страницы в течение staleTime
- **WHEN** пользователь открывает страницу `/clients`, затем переходит на другую страницу, затем возвращается на `/clients` в течение 5 минут
- **THEN** система отображает данные из кеша TanStack Query без нового запроса к API
- **THEN** skeleton loader не отображается
